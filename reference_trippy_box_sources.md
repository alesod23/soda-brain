Verified 2026-09-16 on the Rome→Milan board (`app/trips/rome-milan-2026-09`, generated by its `build.py` from `raw/`):

- **Trenitalia LeFrecce BFF works from the box IP** (POST `.../website/ticket/solutions`, no auth): real prices for FR/IC/NI/regional, 10 solutions per window, so sweep several `departureTime` windows and dedupe. "Roma (Tutte Le Stazioni)" id 830008349, "Milano (Tutte Le Stazioni)" 830001650.
- **Italo cannot be priced headlessly**: italotreno.com is a React/ASP app, no JSON endpoint in the bundle, Trainline SEO timetable carries no operator. Flag it on the board ("check italotreno.com"); never estimate its fares.
- **gflights** (`python3 gflights.py sweep --spec spec.json --json`, spec = `{"cells":[{from,to,date}],"opts":{"max_stops":1}}`) and **FlixBus** (`ground2.py search Rome Milan DD.MM.YYYY`) are live from the box.
- **Render check without playwright**: `~/.cache/ms-playwright/chromium_headless_shell-1234/chrome-headless-shell-linux64/chrome-headless-shell --headless --no-sandbox --virtual-time-budget=8000 --dump-dom <url>` then grep a card id / `rcard dead`.
- Rome→Milan facts: no nonstop FCO→MXP/BGY, nothing from CIA; only ITA FCO→LIN (Sat night €115, Sunday €280+). Frecciarossa €75-86 is the default answer.
