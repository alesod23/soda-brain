Lobbly (lobbly.tech) is Alessandro and Caleb's startup. April 2026 one-pager pitches Siemens with an "agentic layer for inventions" — three modules: Enrich → Screen → Uncover invention disclosures (IDFs). Architecture: on-prem GPU, Siemens IdP/SSO, air-gap supported, 0 bytes leave perimeter. KPIs from an enterprise software customer case study: 60% time savings on deferred-disclosure triage, 95% IDF screening accuracy on true negatives at intake.

**Product shape (V1 edits):**
Inbox-centric workflow around the disclosure. Sidebar: Inbox on top, then Surface Inventions, Connectors (analyze), Routines/Hooks (automation), Rules/IP Playbook (screen — knowledge base of the company's IP strategy + prior drafts + playbook). The "IP Playbook" is company-specific and learned. Inside an inbox item: minimal debrief → prior-art process surfaced → prompting widget for context retrieval → drafting widget (v0 system-suggested, v1 attorney-led with guardrails). Save-to-card pattern on the left.

**Core hypotheses being validated:**
1. AI-generated invention disclosures are flooding in-house IP departments ("AI slop")
2. Attorney cognitive capacity is becoming the bottleneck, not drafting throughput
3. 85% of attorney time is on planning / coordination / clarification, only 15% on actual drafting
4. 50% of patents delayed by misdirected or incomplete invention disclosures
5. 1 week per month spent triaging IDFs, with half not selected

**Customer profile:** Siemens, Philips, Bosch, GE, Samsung, IBM, Volvo, Ericsson, Roche, Bayer-scale in-house IP teams. Two-tier internal structure (analysts + attorneys), central team + BU-embedded "IP managers." Siemens itself: 350 people total, 250 patent professionals, 100 paralegals, 15–20 international antennas, ~2,500–3,000 new apps/year, ~25,000–30,000 live families. Beat Weibel is the named Chief IP Counsel and a public advocate of the Industry Patent Quality Charter.
